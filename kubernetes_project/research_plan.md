# Research Topic

## Title

Characterizing Crash and Byzantine-Like Failures
in the Kubernetes Control Plane

## Research Question

How do crash failures and selective communication failures
differently affect Kubernetes availability and convergence?

## Target Components

- etcd
- kube-apiserver
- Control Plane communication

## Faults

- Replica crash
- Leader crash
- Network delay
- Selective network partition

## Out of Scope

- PBFT implementation
- HotStuff implementation
- Blockchain
- Worker Node failures
