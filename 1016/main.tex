\begin{frame}{Background and Motivation}

\begin{itemize}
\item Parallel exploration
\item Different hypotheses
\item Specialized roles
\end{itemize}
\end{block}
\column{.48\textwidth}
\begin{block}{Why coordinate?}
\begin{itemize}
\item Reuse discoveries
\item Check candidate results
\item Avoid wasted work
\end{itemize}
\end{block}
\end{columns}
\vspace{5mm}
\begin{center}\large\bfseries Does cooperation outperform independent search?\end{center}
\pnote{An inspiration came from recent AI-assisted mathematics research. Parallel agents could explore different ideas and share useful results. But this benefit should not be assumed. We must compare cooperation with independent parallel search using the same compute budget.}
\end{frame}

\begin{alertblock}{Interpretation}
Multi-agent architecture $\neq$ proven multi-agent advantage.
\end{alertblock}
\pnote{Bolzano reports meaningful mathematical research outcomes. However, those outcomes do not isolate the effect of using multiple provers. We need controlled comparisons between single-agent search, independent parallel agents, and agents that share verified information. This distinction is essential for motivation.}

\begin{frame}{Possible Distributed-Systems Problem}
\begin{center}
\Large\bfseries When should agents share intermediate results?
\end{center}
\vspace{5mm}
\begin{columns}[T,onlytextwidth]
\column{.48\textwidth}
\begin{block}{Share early}
\begin{itemize}
\item Faster reuse
\item Risk of unverified claims
\end{itemize}
\end{block}
\column{.48\textwidth}
\begin{block}{Share after checking}
\begin{itemize}
\item Higher confidence
\item Extra delay and cost
\end{itemize}
\end{block}
\end{columns}
\vspace{4mm}
\centering\small Hypothesis: verification and propagation timing affect search efficiency.
\pnote{One idea is to study when intermediate discoveries should be shared. Early sharing may avoid duplicate work, but it can spread incorrect claims. Waiting for verification may be safer but slower. This could connect to distributed information propagation and consistency, although novelty over existing systems research is not established.}
\end{frame}
